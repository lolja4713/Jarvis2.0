FLUJO DE TRABAJO

De Jarvis a Blender

  1. Añade primitivas a la escena.
  2. Ajusta nombre, posición, escala, giro y color.
  3. Exporta el archivo OBJ con su material MTL.
  4. Abre el OBJ en Blender para esculpir, agregar detalles y preparar el modelo para VRChat.
Este taller crea modelos base con primitivas. La edición avanzada, rigging y exportación de avatar para VRChat se hacen en Blender.
