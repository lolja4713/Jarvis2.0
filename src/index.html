De Jarvis a Blender

  1. Añade primitivas a la escena.
  2. Ajusta nombre, posición, escala, giro y color.

  4. Abre el OBJ en Blender para esculpir, agregar detalles y preparar el modelo para VRChat.

✧

Ollama ejecuta modelos en esta computadora. No hay cobro mensual ni por mensaje. El modelo usa espacio y recursos de tu PC.

Buscando Ollama…
Se necesita instalar Ollama y descargar un modelo gratuito. Eso ocupa disco y depende de la memoria y velocidad de tu PC. Jarvis envía las preguntas solo a Ollama en este equipo. El historial se guarda localmente.
